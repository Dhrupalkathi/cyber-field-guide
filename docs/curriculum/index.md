# CINS Curriculum

This page is the **single source of truth for the CINS learning structure**. It records the intended stage sequence, the scope of each stage, and which curriculum pages are available. It does not repeat the teaching content from the individual stage pages.

## Curriculum map

| Stage | Scope | Site availability |
|---|---|---|
| **Stage 0 — Orientation and Cybersecurity Awareness** | What cybersecurity covers, security domains, ethics, authorization, safe learning, personal security, and career awareness. | Published on this site |
| **Stage 1 — Computer Fundamentals** | Computer components, data representation, software, files, processes, virtualisation concepts, and troubleshooting concepts. | Published on this site |
| **Parallel track — Python** | Introductory computational thinking and Python, taught alongside Stage 1 and continued in later stages. | Published on this site |
| **Stage 2 — Technology Foundations** | Networking → Linux → Windows → Internet and Web fundamentals. | All four parts published |
| **Stage 3 — Cybersecurity Core** | Shared security principles, risk, controls, identity, cryptography, vulnerability management, secure development, threat modelling, monitoring, incident response, resilience, and governance. | Published on this site |
| **Stage 4 — Domain Exploration** | Guided exposure to offensive and defensive domains, investigation, intelligence, engineering, operations, and governance. | Draft prepared on review branch |
| **Stage 5 — Specialisation and Advanced Study** | Deeper study in selected fields based on prerequisites and learner interest. | Planned |

## Curriculum boundaries

- A stage page owns its topic explanations and learner guidance. Other pages should link to it rather than repeat that material.
- The resource library lists external sources by subject and labels the CINS stage(s) they support.
- Tool pages explain individual tools and their prerequisites; a tool's presence in the library does not make it a required part of a stage.
- Stage status is explicit. Planned material and review drafts are not presented as published curriculum.
