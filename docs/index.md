## Cybersecurity is bigger than penetration testing

This guide intentionally gives space to both offensive and defensive security.

| Understand and assess | Protect and investigate |
|---|---|
| Reconnaissance and asset discovery | Asset inventory and exposure management |
| Vulnerability assessment | Secure configuration and patching |
| Web and network security testing | Network monitoring and detection |
| Controlled exploitation labs | Incident response and recovery |
| Identity and privilege assessment | Identity hardening and access reviews |

Other areas—including digital forensics, malware analysis, reverse engineering, cloud security, threat intelligence, secure coding, and governance—will be added as the content is researched and reviewed.

## A suggested first route

1. Learn basic computer and operating-system concepts.
2. Understand IP addresses, DNS, ports, TCP, and HTTP.
3. Practise terminal navigation and basic Linux commands.
4. Learn how to read requests, logs, and network traffic.
5. Choose a learning path and use tools only when you understand their purpose.

## How trustworthy is this page?

This project is in its early build stage. Each entry will show its review status. A link to an external course is not a claim that the club has tested or endorsed the entire course.

> **Safety rule:** Only practise on systems you own or have explicit permission to test. Use local labs and platforms that are specifically designed for security training.

The project is currently maintained in an individual GitHub account and is intended to support the CINS community. Its formal status as an official club resource requires club approval.
