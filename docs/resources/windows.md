# Windows Resources

> **CINS stage fit:** Stage 2 — Windows. The detailed CINS Windows curriculum is published in the Stage 2 sequence after Networking and Linux.

This page is the canonical collection for Windows operating-system learning and official references. The [Stage 2 — Windows curriculum](../curriculum/stage-2-windows.md) defines what CINS learners should study. External courses and documentation support that curriculum; they do not replace or reorder it.

## Official Windows foundations

### Microsoft Learn — Windows documentation

> **CINS stage fit:** Stage 2 — Windows; reference across later stages  
> **Level:** Beginner to advanced · **Type:** Official product documentation

The central Microsoft documentation collection for Windows client and related technologies. Use the Windows client and fundamentals material first. Server administration and enterprise deployment pages are useful references but are not prerequisites for this CINS foundation.

- **Access:** Free public documentation.
- **Official resource:** [Windows documentation](https://learn.microsoft.com/en-us/windows/)
- **Useful sections:** Windows client management, Windows security, deployment, troubleshooting, and system configuration.
- **Review state:** Official documentation entry point checked 9 November 2026.

### Microsoft Learn — PowerShell documentation

> **CINS stage fit:** Stage 2 — Windows; reference across later system administration and defensive learning  
> **Level:** Beginner to advanced · **Type:** Official shell and scripting documentation

Explains PowerShell concepts, cmdlets, pipelines, objects, scripting, modules, and command discovery. Start with the introductory concepts and basic cmdlets. Advanced remoting, automation, and enterprise management are later topics.

- **Access:** Free public documentation.
- **Official resource:** [PowerShell documentation](https://learn.microsoft.com/en-us/powershell/)
- **Useful sections:** [PowerShell overview](https://learn.microsoft.com/en-us/powershell/scripting/overview), [PowerShell 7 documentation](https://learn.microsoft.com/en-us/powershell/).
- **Review state:** Official documentation checked 9 November 2026.

### Microsoft Learn — Windows security

> **CINS stage fit:** Stage 2 — Windows; reference across later defensive learning  
> **Level:** Beginner to advanced · **Type:** Official security documentation

Introduces Windows security features from hardware and operating-system protection through application security and identity protection. For this stage, focus on understanding the purpose and limits of features such as Secure Boot, TPM, BitLocker, Microsoft Defender, SmartScreen, UAC, and Windows Firewall. Do not disable protections to experiment.

- **Access:** Free public documentation.
- **Official resource:** [Windows security documentation](https://learn.microsoft.com/en-us/windows/security/)
- **Review state:** Official documentation checked 9 November 2026.

### Microsoft Learn — Access control overview

> **CINS stage fit:** Stage 2 — Windows; reference across later identity and access-management learning  
> **Level:** Developing learner · **Type:** Official technical documentation

Explains Windows access control, security principals, SIDs, permissions, ownership, inheritance, access-control lists, and auditing. It is a deeper reference for the identity and permissions concepts introduced in the CINS curriculum.

- **Access:** Free public documentation.
- **Official resource:** [Access control overview](https://learn.microsoft.com/en-us/windows/security/identity-protection/access-control/access-control)
- **Related reference:** [Local accounts](https://learn.microsoft.com/en-us/windows/security/identity-protection/access-control/local-accounts).
- **Review state:** Official documentation checked 9 November 2026.

### Microsoft Learn — Windows command reference

> **CINS stage fit:** Stage 2 — Windows; reference across later troubleshooting and administration  
> **Level:** Beginner to advanced · **Type:** Official command reference

A reference for Windows command-line tools. Check whether a command is intended for Command Prompt, PowerShell, or another environment, and read its parameters and warnings before using it.

- **Access:** Free public documentation.
- **Official resource:** [Windows commands](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/windows-commands)
- **Review state:** Official reference located 9 November 2026.

## Troubleshooting and operating-system reference

### Microsoft Learn — Windows startup troubleshooting

> **CINS stage fit:** Stage 2 — Windows; selected concepts support later troubleshooting  
> **Level:** Developing learner to advanced · **Type:** Official troubleshooting documentation

Explains the broad phases of Windows startup and common failure categories. The detailed repair procedures are intended for support professionals and should not be treated as beginner experiments. Use the CINS curriculum's conceptual boot sequence first.

- **Access:** Free public documentation.
- **Official resource:** [Windows startup issues troubleshooting](https://learn.microsoft.com/en-us/troubleshoot/windows-client/performance/windows-boot-issues-troubleshooting)
- **Review state:** Official documentation checked 9 November 2026.

### Microsoft Support — Firewall and network protection

> **CINS stage fit:** Stage 2 — Windows; connects to Stage 2 Networking  
> **Level:** Beginner · **Type:** Official user support documentation

Explains Windows Firewall and network profiles in the Windows Security app. Read this to understand the difference between public, private, and domain network profiles. Do not turn off the firewall as a troubleshooting shortcut.

- **Access:** Free public support documentation.
- **Official resource:** [Firewall and network protection](https://support.microsoft.com/en-us/windows/firewall-and-network-protection-in-the-windows-security-app-ec0844f7-aebd-0583-67fe-601ecf5d774f)
- **Review state:** Official support destination checked 9 November 2026.
