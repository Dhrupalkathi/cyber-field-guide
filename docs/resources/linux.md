# Linux and Kali Resources

Kali Linux is not the first lesson. Linux fundamentals are.

## Recommended starting resources

### OverTheWire — Bandit

- **Type:** Command-line wargame
- **Level:** Beginner
- **Best for:** Learning shell navigation, files, permissions, text processing, and other command-line basics through progressive challenges.
- **Prerequisites:** Ability to connect using SSH; the first level explains how to begin.
- **Access:** Public training game.
- **Link:** [OverTheWire Bandit](https://overthewire.org/wargames/bandit/)
- **Review state:** Official game page link checked; challenge walkthroughs are not reproduced here.

### Kali Linux Documentation

- **Type:** Official operating-system documentation
- **Level:** Beginner to advanced
- **Best for:** Installation, package management, system usage, and understanding Kali-specific features.
- **Important:** Read [Should I use Kali Linux?](https://www.kali.org/docs/introduction/should-i-use-kali-linux/) before installing it. You do not need Kali to learn general cybersecurity.
- **Link:** [Kali Linux Documentation](https://www.kali.org/docs/)
- **Review state:** Official documentation link checked.

- **Access:** Module availability and free/paid access can change; check current terms.

## Safe learning order

1. Learn everyday shell navigation and file operations.
2. Understand users, groups, and file permissions.
3. Learn package installation and updates.
4. Practise SSH in training environments.
5. Learn process and service inspection.
6. Only then install a specialist distribution in a virtual machine if a lab requires it.

Never paste a command into your terminal without understanding what it does, especially commands that download and execute scripts or change system security settings.
