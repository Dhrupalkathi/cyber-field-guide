# Linux and Kali Resources

Kali Linux is not the first lesson. Linux fundamentals are. You can begin on the operating system already installed on your laptop.

## Learn Linux without installing Kali

### Linux Journey

- **Type:** Interactive learning website
- **Level:** Beginner
- **Best for:** Linux concepts, command-line navigation, text processing, user management, permissions, processes, packages, and networking basics.
- **Access:** The current official Linux Journey site is hosted by LabEx and describes its core learning material as free.
- **Link:** [Linux Journey](https://labex.io/Linuxjourney)
- **Review state:** Current destination checked on 31 October 2026. Note: the old linuxjourney.com address now redirects to this successor page.

### OverTheWire — Bandit

- **Type:** Command-line wargame
- **Level:** Absolute beginner
- **Best for:** Learning shell navigation, files, permissions, text processing, SSH, and problem-solving through progressive challenges.
- **Prerequisites:** A computer with an SSH client and internet access. The first level explains how to connect.
- **Access:** The Bandit game is publicly accessible.
- **Link:** [OverTheWire Bandit](https://overthewire.org/wargames/bandit/)
- **Review state:** Official game page checked on 31 October 2026.

## Begin cybersecurity with a guided foundation

### TryHackMe — Pre Security

- **Type:** Guided learning path with interactive rooms
- **Level:** Beginner / first step
- **Best for:** Computer fundamentals, operating-system basics, introductory coding, networking, web basics, and first security concepts.
- **Why it is recommended:** The current 2026 path explicitly starts with how technology works before moving into security. It is a stronger first step for a complete beginner than jumping straight into Kali.
- **Access:** Check which rooms require a subscription; access can vary.
- **Link:** [TryHackMe Pre Security](https://tryhackme.com/path/outline/presecurity)
- **Review state:** Current path checked on 31 October 2026.

### TryHackMe — Cyber Security 101

- **Type:** Guided learning path
- **Level:** Beginner
- **Best for:** A broad introduction covering networking, Linux, Windows, Active Directory, offensive security, defensive security, and careers.
- **Suggested order:** Use after or alongside Pre Security, not as a replacement for learning basic computer concepts at your own pace.
- **Access:** Check current room and subscription requirements.
- **Link:** [TryHackMe Cyber Security 101](https://tryhackme.com/path/outline/cybersecurity101)
- **Review state:** Current path checked on 31 October 2026.

## Kali Linux documentation

### Kali Linux official documentation

- **Type:** Official operating-system documentation
- **Level:** Beginner to advanced
- **Best for:** Installation, package management, virtual machines, system usage, and understanding Kali-specific features.
- **Important:** Read [Should I use Kali Linux?](https://www.kali.org/docs/introduction/should-i-use-kali-linux/) before installing it. Kali is a specialist distribution; it is not required for learning general cybersecurity.
- **Link:** [Kali Linux Documentation](https://www.kali.org/docs/)
- **Review state:** Official documentation link checked on 31 October 2026.

## Safe learning order

1. Learn everyday shell navigation and file operations.
2. Understand users, groups, and file permissions.
3. Learn package installation and updates.
4. Practise SSH in training environments.
5. Learn process and service inspection.
6. Learn how Linux logs are stored and read.
7. Only then install a specialist distribution in a virtual machine if a course or lab requires it.

Never paste a command into your terminal without understanding what it does, especially commands that download and execute scripts or change system security settings.
