# Linux and Kali Resources

> **CINS stage fit:** Stage 2 — Linux, after the networking component. Kali Linux is an optional specialist environment for later learning; it is not a requirement for learning Linux.

Start with the Linux environment already available on your computer or an approved learning environment. The resources below are the canonical entries for Linux learning. Cross-stage platforms are listed in their primary subject page rather than repeated here.

## Learn Linux fundamentals

### Linux Journey

> **CINS stage fit:** Stage 2 — Linux  
> **Level:** Beginner · **Type:** Interactive learning website

Covers Linux concepts, command-line navigation, text processing, users, permissions, processes, and package management.

- **Access:** The current Linux Journey destination is hosted by LabEx and describes its core learning material as free.
- **Official resource:** [Linux Journey](https://labex.io/Linuxjourney)
- **Review state:** Current destination checked 31 October 2026. The old linuxjourney.com address redirects to this successor page.

### OverTheWire — Bandit

> **CINS stage fit:** Stage 2 — Linux command-line familiarity  
> **Level:** Absolute beginner · **Type:** Command-line wargame

Introduces shell navigation, files, permissions, text processing, SSH, and problem-solving through progressive levels.

- **Prerequisites:** A computer with an SSH client and internet access. The first level explains how to connect.
- **Access:** The Bandit game is publicly accessible.
- **Official resource:** [OverTheWire Bandit](https://overthewire.org/wargames/bandit/)
- **Review state:** Official game page checked 31 October 2026.

## Kali Linux documentation

### Kali Linux Official Documentation

> **CINS stage fit:** After Stage 2 — optional specialist environment; not required for Linux fundamentals  
> **Level:** Beginner to advanced · **Type:** Official operating-system documentation

Covers installation, package management, virtual machines, system use, and Kali-specific features.

- **Important:** Kali is a specialist security distribution. Read [Should I use Kali Linux?](https://www.kali.org/docs/introduction/should-i-use-kali-linux/) before installing it. It is not required for learning general cybersecurity or completing Stage 2 Linux fundamentals.
- **Official resource:** [Kali Linux Documentation](https://www.kali.org/docs/)
- **Review state:** Official documentation checked 31 October 2026.
