# Stage 0 and Stage 1 — Learning Resources

> **Resource review date: 31 October 2026.** Official provider pages were checked for the descriptions below. CINS has not completed every course or independently verified every course section. Access rules, subscriptions, and course structure can change; check the provider before assigning work.

This page follows the [CINS Stage 0/1 curriculum](../curriculum/index.md). It is intentionally short. Newcomers should not be overwhelmed with dozens of courses.

## Stage 0 — Cybersecurity orientation and safety

### TryHackMe — Pre Security (selected section only)

- **Type:** Guided beginner learning path
- **Level:** Beginner
- **Use in CINS:** Use the current **Introduction to Cyber Security** section for introductory exposure to offensive security, defensive security, and cybersecurity careers.
- **Do not assign the whole path as Stage 0.** The 2026 path also contains computer-fundamentals, operating-system, networking, and web material. Use the computer-fundamentals section selectively for Stage 1; defer operating-system, networking, and web sections to their corresponding CINS stages.
- **Access:** Check room-level free/paid access before recommending a required course section.
- **Official link:** [TryHackMe Pre Security](https://tryhackme.com/path/outline/presecurity)
- **Review note:** TryHackMe announced a Pre Security refresh on 18 February 2026. The current path page was checked on 31 October 2026. CINS has not completed the full path.

### CISA — Secure Our World

- **Type:** Public cybersecurity-awareness guidance
- **Level:** Beginner / general audience
- **Use in CINS:** Short reading for personal-security habits: recognize and report phishing, use strong passwords, enable multi-factor authentication, and update software.
- **Best use:** Pair it with Stage 0's private Personal Security Check-up. Students must not submit passwords, recovery codes, or sensitive account screenshots.
- **Official link:** [CISA Secure Our World](https://www.cisa.gov/secure-our-world)
- **Review note:** CISA's official Secure Our World material describes these four protective habits. This is awareness guidance, not a technical course.

### NIST — Cybersecurity Basics (mentor/optional reading)

- **Type:** Introductory reference
- **Level:** Beginner; written for small businesses
- **Use in CINS:** Optional mentor reading to connect cybersecurity hygiene with continuous risk management. Mentors should translate business examples into student, personal-account, and club scenarios.
- **Official link:** [NIST Cybersecurity Basics](https://www.nist.gov/itl/smallbusinesscyber/cybersecurity-basics)
- **Review note:** The page includes MFA, strong passwords, backups, updates, phishing awareness, and ongoing improvement. It is not a student-specific course.

### NIST NICE Framework — career exploration (mentor reference)

- **Type:** Workforce framework
- **Level:** Introductory orientation for students; detailed framework is professional reference material
- **Use in CINS:** Mentors can use the NICE Framework to explain that cybersecurity work is described through work roles, tasks, knowledge, and skills—not just tool names.
- **Current version checked:** NICE Framework Components v2.2.0, released 28 April 2026.
- **Official links:** [NICE Framework Resource Center](https://www.nist.gov/itl/applied-cybersecurity/nice/nice-framework-resource-center) · [v2.2.0 release note](https://www.nist.gov/news-events/news/2026/04/nice-releases-nice-framework-components-v220)
- **Review note:** Students do not need to read the full framework in Stage 0. Use it to support career conversations.

## Stage 1 — Computer fundamentals

### Khan Academy — Computers and the Internet (selected units)

- **Type:** Free online learning course with videos, examples, and mastery checks
- **Level:** Beginner
- **Use in CINS:** Select **Unit 1: Digital Information** and **Unit 2: Computers** for bits/bytes, binary, hexadecimal, text representation, computer components, CPU, memory, input/output, and files.
- **Defer:** Unit 3: The Internet and networking-related material to Stage 2. Units on online data security can be used later when they align with the security curriculum.
- **Official link:** [Khan Academy — Computers and the Internet](https://www.khanacademy.org/computing/computers-and-internet)
- **Review note:** The current course page lists five units and a course challenge. CINS has not completed the whole course.

### Cisco Networking Academy — Computer Hardware Basics

- **Type:** Self-paced course with guided content and labs
- **Level:** Beginner
- **Use in CINS:** Optional enrichment for students who want deeper exposure to desktops, laptops, mobile devices, components, device maintenance, and hardware troubleshooting.
- **Current provider details checked:** Cisco currently lists it as free, beginner-level, self-paced, approximately six hours, with three labs.
- **Prerequisites:** None are listed by the provider.
- **Official link:** [Computer Hardware Basics](https://www.netacad.com/courses/computer-hardware-basics)
- **Review note:** This is optional enrichment, not a prerequisite. Learners do not need to disassemble their own laptop or buy hardware.

### TryHackMe — Pre Security (Computer Fundamentals section only)

- **Type:** Guided learning path section
- **Level:** Beginner
- **Use in CINS:** Selected Computer Fundamentals material can reinforce Stage 1 topics such as components, computer types, client-server basics, virtualisation basics, and cloud-computing fundamentals.
- **Defer:** Operating Systems Basics, Linux CLI, Windows CLI, and subsequent networking/web sections to Stage 2 in the CINS sequence.
- **Official link:** [TryHackMe Pre Security](https://tryhackme.com/path/outline/presecurity)
- **Review note:** Use the current path outline because the legacy path was refreshed in February 2026. Room access can vary.

## Stage 1 — Python programming (parallel track)

### Harvard — CS50's Introduction to Programming with Python (CS50P)

- **Type:** Structured OpenCourseWare course with lectures, problem sets, and final project
- **Level:** Beginner; designed for learners with or without prior programming experience
- **Use in CINS:** The primary structured Python resource. Select the material that maps to Stage 1: functions and variables, conditionals, loops, and suitable introductory learning with collections and code verification.
- **Do not force the entire course into Stage 1.** CS50P also covers exceptions, libraries, file I/O, regular expressions, object-oriented programming, and other subjects. Later topics can be revisited in future CINS stages.
- **Software:** The course says a web browser is sufficient; students may also use their own computer.
- **Access:** OpenCourseWare course materials can be followed free. An edX account is needed if a learner wants to submit problem sets/final project for feedback through the course workflow; a verified certificate is a separate option.
- **Official link:** [CS50P](https://cs50.harvard.edu/python/)
- **Review note:** Current course topics and the browser-only option were checked on 31 October 2026. CINS has not completed the course.

### Python.org — Getting Started

- **Type:** Official Python entry point and beginner-resource directory
- **Level:** Beginner
- **Use in CINS:** Find official downloads, beginner guides for non-programmers, setup guidance, and documentation.
- **Official link:** [Python.org — Getting Started](https://www.python.org/about/)
- **Review note:** Use the Beginner's Guide for Non-Programmers when selecting supplementary material. Avoid directing a complete beginner straight to an advanced reference.

### Python official tutorial — reference, not the first course

- **Type:** Official language tutorial/reference
- **Level:** Beginner-to-intermediate reference for people who already understand basic programming
- **Use in CINS:** Look up syntax and language behavior after students have learned introductory programming concepts.
- **Important caveat:** Python's own documentation says the tutorial is for programmers new to Python, not people new to programming. Do not make it the sole first course for absolute beginners.
- **Official link:** [The Python Tutorial](https://docs.python.org/3/tutorial/)
- **Review note:** The official documentation's intended audience was checked on 31 October 2026.

## Videos and supplementary learning

Video channels should support a structured curriculum, not replace it. Use the [CINS YouTube channel directory](video-channels.md) for supplementary educators. In particular, Bitten Tech is listed under networking and belongs with Stage 2—not as a Stage 0/1 assignment.

For each recommended video, contributors should link to the exact playlist or video, record its publication date where version-sensitive, identify its intended level, and cross-link official documentation. Do not certify a whole channel because one video was useful.

## Stage 0/1 resource selection rule

- One primary resource per learning goal is enough to begin.
- Optional enrichment must be clearly labelled.
- Stage 0/1 learners should not be sent to Nmap, Burp Suite, Kali Linux, SIEM deployments, or exploitation tools.
- Course modules that mix several CINS stages must be assigned selectively.
- Record whether a link was checked, the content reviewed, or the course section completed. These are different levels of verification.
