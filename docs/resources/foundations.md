# Foundations & Computing Resources

This page holds resources whose primary subject is introductory cybersecurity awareness, computer fundamentals, or beginner programming. Each entry identifies its CINS stage fit.

## Stage 0 — Cybersecurity awareness

### CISA — Secure Our World

> **CINS stage fit:** Stage 0 — Orientation  
> **Level:** Beginner · **Type:** Public awareness guidance

Covers practical account and device-security habits, including recognizing and reporting phishing, using strong passwords, enabling multi-factor authentication, and updating software.

- **Use it for:** Supporting Stage 0 awareness and personal-security topics.
- **Access:** Public guidance.
- **Official resource:** [CISA Secure Our World](https://www.cisa.gov/secure-our-world)
- **Review state:** Official page checked 31 October 2026. This is awareness guidance, not a technical course.

### NIST — Cybersecurity Basics

> **CINS stage fit:** Stage 0 — Orientation (optional mentor reference)  
> **Level:** Beginner · **Type:** Introductory reference

A small-business-oriented introduction to cybersecurity hygiene. Mentors can use it to discuss updates, MFA, backups, phishing awareness, and risk management, translating business examples into student and personal-account contexts.

- **Use it for:** Optional background reading; it is not a required student course.
- **Official resource:** [NIST Cybersecurity Basics](https://www.nist.gov/itl/smallbusinesscyber/cybersecurity-basics)
- **Review state:** Official page checked 31 October 2026.

### NIST NICE Framework — Career Exploration

> **CINS stage fit:** Reference — useful during Stage 0 career awareness and later career exploration  
> **Level:** Beginner overview; detailed framework is professional reference · **Type:** Workforce framework

Introduces a shared vocabulary for cybersecurity work roles, tasks, knowledge, and skills. It helps explain that a cybersecurity career is more than a list of tools.

- **Use it for:** Mentor-led career orientation. Students do not need to read the full framework in Stage 0.
- **Version checked:** NICE Framework Components v2.2.0, released 28 April 2026.
- **Official resources:** [NICE Framework Resource Center](https://www.nist.gov/itl/applied-cybersecurity/nice/nice-framework-resource-center) · [v2.2.0 release note](https://www.nist.gov/news-events/news/2026/04/nice-releases-nice-framework-components-v220)
- **Review state:** Official NIST pages checked 31 October 2026.

## Stage 1 — Computer Fundamentals

### Khan Academy — Computers and the Internet

> **CINS stage fit:** Stage 1 — Computer Fundamentals (selected units)  
> **Level:** Beginner · **Type:** Online course with videos and mastery checks

Use **Unit 1: Digital Information** and **Unit 2: Computers** for bits and bytes, binary, hexadecimal, text representation, computer components, CPU, memory, input/output, and files.

- **Defer:** Internet and networking material to Stage 2. Do not treat the full course as a Stage 1 assignment.
- **Access:** The course is publicly available; check the provider page for current account and course details.
- **Official resource:** [Khan Academy — Computers and the Internet](https://www.khanacademy.org/computing/computers-and-internet)
- **Review state:** Course outline checked 31 October 2026; CINS has not completed the full course.

### Cisco Networking Academy — Computer Hardware Basics

> **CINS stage fit:** Stage 1 — Computer Fundamentals (optional enrichment)  
> **Level:** Beginner · **Type:** Self-paced course

Introduces desktops, laptops, mobile devices, computer components, device maintenance, and hardware troubleshooting.

- **Use it for:** Additional hardware context for learners who want more depth.
- **Access:** Cisco listed the course as free and self-paced when checked; account/enrollment requirements may apply.
- **Official resource:** [Computer Hardware Basics](https://www.netacad.com/courses/computer-hardware-basics)
- **Review state:** Provider course details checked 31 October 2026. This is optional enrichment, not a prerequisite.

## Stage 1 — Parallel Python Track

### Harvard — CS50's Introduction to Programming with Python (CS50P)

> **CINS stage fit:** Stage 1 — Parallel Python Track (selected introductory topics)  
> **Level:** Beginner · **Type:** Structured OpenCourseWare course

A structured introduction to Python for learners with or without prior programming experience. Use the introductory material that supports variables, functions, conditionals, loops, basic collections, and debugging.

- **Defer:** More advanced topics such as file I/O, regular expressions, libraries, and object-oriented programming until the learner has the necessary foundations and the CINS curriculum introduces them.
- **Software:** The course supports browser-based learning; local installation is optional.
- **Access:** OpenCourseWare material is available online. edX feedback/certification options have separate account and fee conditions.
- **Official resource:** [CS50P](https://cs50.harvard.edu/python/)
- **Review state:** Official course outline checked 31 October 2026; CINS has not completed the course.

### Python.org — Beginner Resources

> **CINS stage fit:** Stage 1 — Parallel Python Track  
> **Level:** Beginner · **Type:** Official language resource directory

Use the beginner resources for people who are new to programming, official downloads, and setup information. Choose a beginner-oriented guide rather than sending a first-time programmer directly to a language reference.

- **Official resource:** [Python.org — About and Getting Started](https://www.python.org/about/)
- **Review state:** Official entry point checked 31 October 2026.

### Python Official Tutorial

> **CINS stage fit:** Stage 1 — Parallel Python Track (reference after introductory programming concepts)  
> **Level:** Beginner-to-intermediate reference · **Type:** Official documentation

The Python tutorial is useful for looking up syntax and language behavior after a learner has some programming understanding.

- **Important audience note:** Python's documentation says the tutorial is for programmers who are new to Python, not people who are new to programming. It should not be the only first course for an absolute beginner.
- **Official resource:** [The Python Tutorial](https://docs.python.org/3/tutorial/)
- **Review state:** Official documentation and intended audience checked 31 October 2026.
