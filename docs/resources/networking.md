## Cross-stage resource: introductory computing, security, and networking

### TryHackMe — Pre Security

> **CINS stage fit:** Stage 0, Stage 1, and Stage 2 — selected sections only  
> **Level:** Beginner · **Type:** Guided learning path with interactive rooms

This path spans several subjects. Use only the sections that match the current CINS stage:

- **Stage 0:** introductory cybersecurity material, including the introduction to the field and its offensive/defensive domains.
- **Stage 1:** Computer Fundamentals material that supports the CINS computer-fundamentals topics.
- **Stage 2:** networking-related rooms whose topics match the published [Stage 2 Networking modules](../curriculum/stage-2-networking.md). Check the current room outline before starting; do not treat the platform's overall path order as CINS progression.

Defer operating-system administration and web material until those subjects are introduced in the CINS curriculum.

- **Access:** Room-level free/paid access can vary; check the current platform page before relying on a room.
- **Official resource:** [TryHackMe Pre Security](https://tryhackme.com/path/outline/presecurity)

## Networking course

### Cisco Networking Academy — Networking Basics

> **CINS stage fit:** Stage 2 — Networking  
> **Level:** Beginner · **Type:** Self-paced course

Covers network devices, media, protocols, Ethernet communication, IPv4 and IPv6 addressing, DHCP, network segmentation, gateways, routing, TCP/UDP, ports, application services, DNS, troubleshooting, and wireless networking. These topics align closely with the CINS Networking modules.

- **Prerequisites:** Cisco lists no prerequisites.
- **Access:** Cisco listed the course as free when checked; account and enrollment steps may apply.
- **Official resource:** [Networking Basics](https://www.netacad.com/courses/networking-basics)
- **Review state:** Provider course outline checked 2 November 2026; CINS has not completed or verified every course activity.

## Concepts covered in this subject area

- Network types, devices, media, and protocol models.
- Ethernet, MAC addresses, switching, ARP, and IPv6 neighbour discovery.
- IPv4, IPv6, CIDR prefixes, and subnet foundations.
- DHCP, DNS, gateways, routing, and NAT.
- TCP, UDP, ports, and common services.
- Wi-Fi, firewalls, segmentation, VPNs, and basic network security.
- Basic network troubleshooting and local-device diagnostics.

HTTP/HTTPS are introduced here as familiar service examples; detailed web-protocol behaviour belongs to the later Internet and Web Fundamentals part of Stage 2.

These concepts support later network monitoring and security work. Do not scan or capture traffic from systems or networks without explicit authorization.
