# Learning Paths

A learning path is a sequence of concepts, resources, and practical exercises that helps someone move from a starting level toward a defined skill.

It is different from a list of tools. A path should explain **what to learn first, why it matters, how to practise, and how to know when to move on**.

## Common foundation first

Every learner should complete the common foundation before choosing a specialist route:

- [Stage 0 — Orientation](../curriculum/stage-0.md)
- [Stage 1 — Computer Fundamentals](../curriculum/stage-1-computer-fundamentals.md)
- [Parallel Stage 1 Python Track](../curriculum/stage-1-python-track.md)

The next shared technical foundation is Stage 2 Networking, followed by Linux, Windows, and Internet/Web fundamentals in the agreed order. Learners may use prior knowledge to move faster, but should demonstrate the relevant outcomes before skipping prerequisites.

## Planned paths

| Path | First foundations | Later practice |
|---|---|---|
| Networking and infrastructure security | TCP/IP, DNS, routing, Linux | Traffic analysis, asset discovery, network defense |
| Linux and security operations | Shell, files, users, permissions, logs | Host monitoring, hardening, incident triage |
| Web and API security | HTTP, browser behavior, sessions, databases | PortSwigger labs, local vulnerable applications, secure remediation |
| SOC and blue team | Networking, Windows/Linux logs, security principles | Alert triage, SIEM, detection, incident response |
| Digital forensics and incident response | Filesystems, logs, evidence handling | Lab-based investigation and reporting |
| Cloud and identity security | Networking, IAM, shared-responsibility concepts | Cloud configuration review, identity hardening, audit analysis |

## What a complete path must contain

- Target learner and prerequisites.
- Learning outcomes that can be demonstrated.
- A sequence of concepts and resources.
- Practice tasks with safe boundaries.
- A small project or assessment.
- Estimated effort, with a note that learners progress at different speeds.
- Review owner, evidence sources, and last-review date.

Paths will be added gradually. We will not publish an incomplete path as a guaranteed career roadmap.
