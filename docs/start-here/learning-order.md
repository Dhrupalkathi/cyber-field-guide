# A sensible learning order

This is a starter sequence, not a race or a rigid timetable. Spend more time on a topic when you need it.

## Stage 1 — Understand computers

Learn what an operating system does, how files and processes work, what a user account is, and why permissions matter.

**Checkpoint:** Explain the difference between a file, a process, a user, and an administrator/root account.

## Stage 2 — Understand networks

Learn the purpose of IP addresses, DNS, ports, TCP, UDP, routing, and HTTP/HTTPS. Begin with a networking course rather than a port scanner.

**Checkpoint:** Explain what happens at a high level when you open a website in a browser.

## Stage 3 — Become comfortable with a terminal

Practise listing files, moving between directories, reading text files, searching text, and understanding file permissions. OverTheWire Bandit is one optional practice resource.

**Checkpoint:** Complete basic file-navigation and text-inspection tasks without blindly copying commands.

## Stage 4 — Understand web applications

Learn the client/server model, HTTP methods, status codes, headers, cookies, sessions, forms, and browser developer tools.

**Checkpoint:** Identify the method, path, headers, and body in a sample HTTP request.

## Stage 5 — Learn security thinking

Understand assets, threats, vulnerabilities, risk, authentication, authorization, logging, least privilege, patching, and responsible disclosure.

**Checkpoint:** Given a simple scenario, explain what should be protected, what could go wrong, and how to reduce the risk.

## Stage 6 — Choose a direction

Try a small, authorized exercise in one area. Compare what you enjoy:

- Network and infrastructure security
- Web and API security
- Security operations and detection
- Digital forensics and incident response
- Cloud and identity security
- Secure development and application security
- Reverse engineering and malware analysis

Do not choose a specialization based only on the tools that look exciting. Learn the underlying concepts and the day-to-day work first.
