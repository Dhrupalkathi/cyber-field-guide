# Start Here

## Welcome, beginner

This guide assumes you may be completely new to cybersecurity. You may not know what Kali Linux is, what a port means, or why people use a terminal. That is fine.

**Do not start by installing every hacking tool.** First understand the systems and networks those tools interact with.

## What you should learn first

| Order | Topic | What you should be able to explain |
|---|---|---|
| 1 | Computer fundamentals | Files, processes, memory, operating systems, users, and permissions |
| 2 | Networking fundamentals | IP addresses, DNS, ports, TCP/UDP, routing, and HTTP/HTTPS |
| 3 | Linux and terminal | Navigate directories, inspect files, manage permissions, and understand command output |
| 4 | Web fundamentals | Requests, responses, headers, cookies, sessions, and basic HTML/JavaScript concepts |
| 5 | Security fundamentals | Authentication, authorization, confidentiality, integrity, availability, risk, and ethics |
| 6 | Safe practice environments | Use a local virtual machine or a purpose-built training platform |

Follow the [suggested learning order](learning-order.md) for a manageable first sequence.

## Do I need Kali Linux?

No. Kali Linux is a specialist security distribution, not a prerequisite for learning cybersecurity. Start with the operating system you already have. Learn basic Linux commands in a safe environment first; install Kali in a virtual machine later when a course or lab genuinely requires it.

Official reading: [Should I use Kali Linux?](https://www.kali.org/docs/introduction/should-i-use-kali-linux/).

## Your first practice activities

- Learn to navigate the terminal and inspect files.
- Understand a DNS lookup and what information it returns.
- Read a sample HTTP request and response.
- Open a supplied packet capture in Wireshark and identify basic protocols.
- Complete beginner challenges on a training platform that explicitly permits the activity.

## What not to do

- Do not scan your college network, public IP ranges, or websites without explicit authorization.
- Do not run random commands copied from videos or repositories without understanding them.
- Do not disable security controls on your everyday laptop to make a tool work.
- Do not upload passwords, API tokens, session cookies, personal data, or private logs to this repository.
