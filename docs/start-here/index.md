# Start Here

This page is a signpost, not a second curriculum. It helps you choose the right part of the guide; the detailed learning sequence lives only in the [Curriculum](../curriculum/index.md).

## New to cybersecurity?

Begin with [Stage 0 — Orientation and Cybersecurity Awareness](../curriculum/stage-0.md). It introduces the field, its different domains, safe learning, and how to explore the subject responsibly.

When you are ready to see how the full CINS programme is organised, use the [Curriculum overview](../curriculum/index.md). The stage pages contain their own topic explanations and AI-guided learning instructions.

## How to work through the curriculum

You do not need to study every page or use every external platform. Use the curriculum as your learning sequence and the resource and tool libraries only when they help with a topic.

1. **Choose your starting point.** If you are completely new, begin at Stage 0. If you already understand a stage's foundations, use the [Curriculum map](../curriculum/index.md) to find the next area you need.
2. **Preview the stage.** Read its purpose, prerequisites, and exit outcomes before starting. They explain what the stage covers and what you should be able to explain by the end.
3. **Study one module at a time.** Read the explanation, examples, and diagrams. Write down unfamiliar terms and questions instead of trying to memorise every detail at once.
4. **Use the page's AI-guided learning prompt when useful.** Ask for a simpler explanation, a worked fictional example, or a step-by-step discussion. Treat AI output as a learning aid, not an authority: verify important claims with the official references and never run a command you do not understand.
5. **Move forward when you can explain the outcomes.** Use your own notes or a small, safe example to check your understanding. There is no required exam, paid course, tool installation, or fixed timetable in this guide.

The **Parallel Programming Track — Python** runs alongside Stage 1 and continues as your programming knowledge develops. It is a companion track, not an extra numbered stage.

For Stage 2, follow the published order: **Networking → Linux → Windows → Internet and Web fundamentals**. Linux is part of Stage 2; Kali Linux and specialist security tools are not prerequisites.

## Already know some fundamentals?

Open the [Curriculum](../curriculum/index.md) and use its stage map to find the material that matches your current knowledge. You do not need to reread topics you already understand.

For the current technical foundations, **Stage 2 is Networking → Linux → Windows → Internet and Web fundamentals**. All four parts are published: [Networking](../curriculum/stage-2-networking.md), [Linux](../curriculum/stage-2-linux.md), [Windows](../curriculum/stage-2-windows.md), and [Internet and Web Fundamentals](../curriculum/stage-2-web-fundamentals.md).

## What comes after the foundations?

[Stage 3 — Cybersecurity Core](../curriculum/stage-3-cybersecurity-core.md) is published. It develops the shared security concepts that connect the technology foundations to the different cybersecurity domains.

After Stage 3, use the published [Stage 4 — Domain Exploration](../curriculum/stage-4-domain-exploration.md) to compare specialist fields, understand their workflows and prerequisites, and decide which area you want to study more deeply.

The next step is the published [Stage 5 — Specialisation and Advanced Study](../curriculum/stage-5-specialisation.md). It provides deeper pathways for learners who are ready to focus on a selected domain.
