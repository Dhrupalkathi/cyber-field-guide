# Contributing to the Guide

You do not need to be an expert to help. Good contributions include fixing a broken link, explaining a term in simpler language, suggesting a quality course, adding an accessibility improvement, or reviewing a tool page against official documentation.

## Before proposing a change

1. Search the guide to check whether the topic already exists.
2. Prefer the official project, course, or documentation link.
3. Explain who the resource is for and what it teaches.
4. Mark uncertain details clearly; do not guess installation commands, prices, or supported operating systems.
5. Keep examples safe and within authorized labs.

## What reviewers look for

- Accuracy and traceable sources.
- Clear beginner-friendly explanations.
- Honest difficulty, prerequisites, and access/cost notes.
- Balanced defensive and offensive context.
- Safe examples and explicit authorization boundaries.
- A review status that reflects what was actually checked.

See the repository's [CONTRIBUTING.md](https://github.com/Dhrupalkathi/cyber-field-guide/blob/main/CONTRIBUTING.md) for the complete proposal workflow.
