# Community Code of Conduct

CINS Cyber Field Guide aims to be a respectful, constructive, and welcoming learning space for beginners, contributors, reviewers, and maintainers.

## Expected behaviour

- Be respectful, patient, and constructive.
- Assume good intent while discussing technical disagreements.
- Critique ideas and evidence, not people.
- Welcome beginner questions and explain unfamiliar terms.
- Give actionable feedback and acknowledge contributions.
- Respect privacy and never publish another person's personal information.
- Keep cybersecurity learning ethical and within explicitly authorized scope.

## Unacceptable behaviour

- Harassment, discrimination, threats, intimidation, or personal attacks.
- Sexualized language or unwelcome advances.
- Publishing private information without permission.
- Deliberate disruption, trolling, or repeated bad-faith conduct.
- Encouraging unauthorized access, harm, or disclosure of secrets in project spaces.

## Maintainer response

Maintainers may edit, reject, or remove contributions that violate this Code and may restrict participation when necessary to protect the community. Responses should be proportionate, documented, and applied consistently.

## Reporting a concern

Do not publish sensitive conduct reports, personal information, credentials, or security details in public issues. Contact a project maintainer privately through the contact route shown on the repository's GitHub profile. If no private contact route is available, ask a maintainer for one without posting the report itself.

## Scope

This Code applies in project issues, pull requests, reviews, and other spaces where someone represents the project.

This document is adapted from the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html).
